Простейший пример создания диалога скриптом, подробнее:
https://www.amk-team.ru/forum/topic/7450-spravochnik-po-funkcijam-i-klassam/page/4/#findComment-467703

Добавим наш диалог в xml

\gamedata\config\gameplay\dialogs.xml

<dialog id="my_hello_dialog">
   <init_func>dialog_manager1.init_simple_exchange_dialog</init_func>
</dialog>


Укажем диалог персонажу

\gamedata\config\gameplay\character_desc_escape.xml

<actor_dialog>my_hello_dialog</actor_dialog>


Создадим скрипт для диалога
\gamedata\scripts\dialog_manager1.script


function init_simple_exchange_dialog(dlg)
  dlg:SetForceReload(true)

    local phr0 = dlg:AddPhrase("Певая фраза", "0", "", -10000)

    local phr1 = dlg:AddPhrase("Вторая фраза", "1", "0", -10000)
    
    local phr2 = dlg:AddPhrase("Третья фраза", "2", "1", -10000)
  
    local phr3 = dlg:AddPhrase("Четвертая фраза", "3", "2", -10000)
end
