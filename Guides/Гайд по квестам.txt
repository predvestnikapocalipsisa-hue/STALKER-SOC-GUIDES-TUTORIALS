Всех приветствую, вот основные пункты создания квестов:
-Квест ВСЕГДА выдаётся с инфопоршн, а завершаться может после получения другого инфопоршн, либо по условиям функций.

-Каждое подзадание выполняется также, либо после получения инфопоршн, либо по условию функции.

-Под функцией понимаетс, например, после взятия предмета или уничтожения лагеря подзадача выполнится.

Есть кшн такой способо из цикличек:
local new_task = CGameTask()
new_task:load("gar_car_graveyard_quest") -- задание "Предложить помощь Бесу"
db.actor:give_task(new_task, 3600*1000, true)

но тут ограничение по времени не обойти, так как в 32-х разрядное целое влазит миллисекунд примерно на месяц. Соответственно - это и будет максимально возможным временем для задания.



0.Разберём то, как можно будет выдавать квест:
-- В  диалоге с персонажем
-- Со старта игры
-- По различным условиям, по типу прийти на определенное место и тд.


В любом случае нужно сначала создать инфопоршн с квестом, в файле \gamedata\config\gameplay\info_portions.xml(файл может быть другой, главное с инфопоршнс)

  <info_portion id="my_kvest_start">
    <task>my_kvest</task>
  </info_portion>

my_kvest_start - имя инфо
my_kvest 	   - имя квеста


0.1.В диалоге инфо выдаётся так:
            <phrase id="101111">
                <text>my_start_dialog_101111</text>
                <give_info>my_kvest_start</give_info>
                <next>1011111</next>
            </phrase>
			
То есть через <give_info>my_kvest_start</give_info>			
	
	
0.2.Чтобы квест начинался со старта игры, нужно выдать этот инфо в \gamedata\scripts\bind_stalker.script
находим
 		if not has_alife_info("level_changer_icons") then
			self.object:give_info_portion("level_changer_icons")
		end
		
и делаем так:		
 		if not has_alife_info("level_changer_icons") then
			self.object:give_info_portion("level_changer_icons")
			self.object:give_info_portion("my_kvest_start") -- добавили выдачу инфо
		end


0.3.Под различными условиями имеется в виду выдача инфопоршн не в диалоге, а например:

-- В логике нпс, когда обыщем труп выдастся инфо esc_tutorial_secre

[known_info]
esc_tutorial_secre

-- В рестрикторе, если игрок внутри, то выдан инфопоршн name_info

[logic]
active = sr_idle

[sr_idle]
on_actor_inside = nil %+name_info%

-- Внутри какого-либо скрипта, когда только при выполнении определенных условий - должен быть выдан инфо:
db.actor:give_info_portion("tutorial_artefact_gain")

1.Приступим к написанию квеста. Открываем \gamedata\config\text\rus\string_table_tasks_escape.xml(или иной файл с ру текстом)
Вставляем:
	<string id="my_kvest">
		<text>Поиск арта</text>
	</string>
	<string id="name_pod_kvest_1">
		<text>Найти арт</text>
	</string>
	<string id="name_pod_kvest_2">
		<text>Принести арт заказчику.</text>
	</string>
	<string id="article_my_kvest">
		<text>Описание квеста</text>
	</string>


Открываем  gamedata/config/gameplay/tasks_escape.xml(или иной файл с квестами)
Вставляем:
	<game_task id="my_kvest" prio="1">
		<title>my_kvest</title>
		<objective>
			<text>my_kvest</text>
			<icon>ui_iconsTotal_find_railroad_passage</icon>
			<infoportion_complete>my_kvest_done</infoportion_complete>
			<article>article_my_kvest</article>
		</objective>
		<objective>
			<text>name_pod_kvest_1</text>
			<function_complete>sak.prov</function_complete>
		</objective>
		<objective>
			<text>name_pod_kvest_2</text>
			<map_location_type hint="escape_trader">blue_location</map_location_type>
			<object_story_id>Escape_Trader</object_story_id>
		</objective>
	</game_task>

---------------------------------------------------------------------------------------------------
Первый <objective>
Обджективы это подзадания, НО первый обджектив является ОСНОВОЙ квеста, и, если выполняется условие написанное в нем в данном случае наличие инфопоршня "my_kvest_done", то квест завершается.
---------------------------------------------------------------------------------------------------


---------------------------------------------------------------------------------------------------
Обджективов может быть сколько угодно.
Наличие двух проверок сразу тоже возможно.
---------------------------------------------------------------------------------------------------


---------------------------------------------------------------------------------------------------
Вариации условий в <objective>:		
			<infoportion_complete>tutorial_artefact_done</infoportion_complete>				// Инфо для выполнения
			
			<infoportion_fail>cit_fail_first_task</infoportion_fail>						// Инфо для провала
			
			<infoportion_set_complete>garbage_meetstalker_start</infoportion_set_complete>  // Инфо для выполнения самого квеста и всех подзаданий	
			
			<function_complete>sak.prov_then</function_complete>							// Функция для выполнения
			
			<function_fail>escape_tasks.task_volk_fail</function_fail>						// Функция для провала
---------------------------------------------------------------------------------------------------			
			

---------------------------------------------------------------------------------------------------		
	<icon>ui_iconsTotal_find_railroad_passage</icon> 
Это иконка задания из \gamedata\config\ui\ui_iconstotal.xml
---------------------------------------------------------------------------------------------------		


---------------------------------------------------------------------------------------------------		
	<article>article_my_kvest</article> 
Это описание квеста, создается в файле \gamedata\config\gameplay\storyline_info_escape.xml(или иной файл с артикулами) 

пишется такая запись:
	<article id="article_my_kvest" name="task" article_type="task"  group="task">	
		<texture x="200" y="650" width="200" height="150">ui\ui_icon_photo</texture>
		<text>article_my_kvest</text>
	</article>

Где name="task" article_type="task"  group="task" для заданий всегда три "task"
"ui_icon_photo" это текстура из \gamedata\textures\ui\ui_icon_photo.dds
<text>article_my_kvest</text> Это соответсвенно ссылка на текст из config\text\rus\ любой файл подойдёт.
---------------------------------------------------------------------------------------------------


---------------------------------------------------------------------------------------------------
	<infoportion_complete>my_kvest_done</infoportion_complete>		
Когда мы получим инфопоршн "my_kvest_done" всё задание завершится целиком.
Закрытие </objective>
---------------------------------------------------------------------------------------------------


---------------------------------------------------------------------------------------------------
Второй <objective> он же первое подзадание, имеет <text> с текстом подзадания
<function_complete>sak.prov</function_complete>
завершается по условеию функции prov из sak.script - проверка на наличие предмета
Закрытие </objective>
---------------------------------------------------------------------------------------------------


---------------------------------------------------------------------------------------------------
Третий <objective> - второе поздадание, в нем можно не указывать условие выполнения, если оно совпадает с тем, которое указано в первом <objective>, но при необходимости можно указать.

	<map_location_type hint="escape_trader">blue_location</map_location_type>
	<object_story_id>Escape_Trader</object_story_id>		
	
hint="escape_trader" - это текст метки из папки config\text\rus\		
"blue_location"	это тип метки (человечик в белом круге, стандартная метка, ещё бывает "green_location" это зелёная метка)
"Escape_Trader" Это стори айди, по нему уже идёт определение цели, стори айди ставится объекту в СДК или ACDC, в асдс указывается номер, а не текст, ещё его можно скриптом задать при спавне.

сами стори айди лежат в \gamedata\config\game_story_ids.ltx и создаются новые там же
у Сидора выглядит так:
003		    = "Escape_Trader"
Закрытие </objective>
---------------------------------------------------------------------------------------------------

-- Это функция проверки наличия у нас медузы
function prov() 
return sak.have_item_namber("af_medusa",1) ~= false
end

-- У нас забирают вещь
function zabral()
sak.out_item_namber("af_medusa",1)
end

-- Дают награду
function nagrada()
sak.create_items_actor("medkit",3)
sak.create_items_actor("bandage",5)
end

ВАЖНО!!! Если вы хотите чтобы за выполнение квеста начислялись очки ранга или репутации, то откройте config/misc/task_manager.ltx
 и находим ;-------STORYLINE TASKS-------
 и дописываем техническое название квеста, у нас это my_kvest 
 
 
 далее находим 
;*************************************************
;** STORYLINE TASKS
;*************************************************
и вставляем 
[my_kvest]
type = storyline
reward_rank = 20 ;очки ранга, которые получим за выполнение
reward_reputation = +7 ;очки репутации, которые получим за выполнение
reward_relation = stalker, +10 ;очки отношения с группировкой, которые получим за выполнение
