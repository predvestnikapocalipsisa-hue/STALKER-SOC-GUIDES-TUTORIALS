Разобранный ниже диалог можно потестить в "Gamedata из гайда по квесту" https://drive.google.com/open?id=10NtSLlxWLDGGx6kY0TgB9Py7uxgtcbmY&usp=drive_fs

Начинаем его мы, то есть актор, а при соблюдении определённых условий появляются новые фразы и разветвления диалога
---------------------------------------------------------------------
Скажу прямо, на глаз разобраться трудно, смотрим мой урок по Диалог_Эдитор и открываем диалог в проге и ознакамливаемся нормально.
---------------------------------------------------------------------------------------------------
Параметры диалога
id - названия

priority - приоритета

<has_info> - инфопоршн для ограничения показа диалога до получения этого\этих поршн(диалог не будет отображаться среди доступных)

<dont_has_info> - инфопоршн для ограничения показа диалога после получения этого\этих поршн(диалог не будет отображаться среди доступных)

<precondition> - функция для ограничения показа диалога до выполнения условий функции - диалог не будет отображаться среди доступных

В этот параметр указывается функция из файла в папке gamedata/scripts/

подробнее в гайде по скриптам
---------------------------------------------------------------------------------------------------
<dialog id="my_actor_dialog"> Это шапка диалога его айди

закрывается так:
</dialog>
---------------------------------------------------------------------------------------------------
<phrase_list> Обязательная часть диалога, содержит в себе все фразы

закрывается так:
</phrase_list>
---------------------------------------------------------------------------------------------------
Параметры фраз

id - номер фразы

<next> - можно установить, какие фразы будут исходить из этой

<has_info> - инфопоршн для ограничения показа фразы до получения этого\этих поршн(фраза не будет отображаться среди доступных)

<dont_has_info> - инфопоршн для ограничения показа фразы после получения этого\этих поршн(фраза не будет отображаться среди доступных)

<give_info> - выдача инфопоршн 

<disable_info> - удаление инфопоршн 

<precondition> - функция для ограничения показа фразы до выполнения условий функции - фраза не будет отображаться среди доступных

<action> - вызов\выполнение функции

В <precondition> и <action> указывается функция из файла в папке gamedata/scripts/

подробнее в гайде по скриптам
---------------------------------------------------------------------------------------------------
Доступность фраз
Если в диалоге не будет доступной фразы для ответа гг или нпс - случится вылет, поэтому всегда предусматриваем такую фразу
---------------------------------------------------------------------------------------------------
            <phrase id="0">
                <text>my_actor_dialog_0</text>
                <next>1</next>
                <next>2</next>
                <next>25</next>
            </phrase>
Каждый диалог начинается с 0 фразы, в actor_dialog её говорим мы и нпс нам ответит фразу 1, либо 2, либо 25, в зависимости от условий их появления.		
---------------------------------------------------------------------------------------------------
в start_dialog можно разнообразить первую фразу, нужно не указывать текст в 0 фразе, тогда фраза отображаться не будет, но зачется как прочитанная
 
            <phrase id="0">
                <text></text>
                <next>1</next>
                <next>2</next>
                <next>3</next>
            </phrase>

Поэтому следующую фразу тоже делаем пустой
            <phrase id="1">
                <text></text>
                <dont_has_info>my_kvest_done</dont_has_info>
                <next>1000</next>
            </phrase>

В первую фрвзу можно поставить доп условия для её закрытия/показа

Во фразе 1000 уже ставим текст, с него начнётся диалог

Так можно сделать много веток диалогов, которые будут показываться в зависимости от выполнения условий
---------------------------------------------------------------------------------------------------
Рвзбор остальных фраз
---------------------------------------------------------------------------------------------------
            <phrase id="1">
                <text>my_actor_dialog_1</text>
                <dont_has_info>my_kvest_done</dont_has_info>
                <next>10</next>
            </phrase>

<dont_has_info>my_kvest_done</dont_has_info> первая ветка диалога работает сразу и до получения инфопоршн "my_kvest_done"
------------------------------------------------------------------------------------------------
---
            <phrase id="101">
                <text>my_start_dialog_101</text>
                <dont_has_info>my_kvest_start</dont_has_info>
                <next>1011</next>
                <next>1012</next>
            </phrase>

<dont_has_info>my_kvest_start</dont_has_info> После получения инфопоршня "my_kvest_start" ветка диалога уберается из игры, если не будет сделан disable инфопоршня. То есть та ветка, в которой мы соглашаемся выполнить квест.
---------------------------------------------------------------------------------------------------
            <phrase id="101111">
                <text>my_start_dialog_101111</text>
                <give_info>my_kvest_start</give_info>
                <next>1011111</next>
            </phrase>

<give_info>my_kvest_start</give_info> Это выдача инфопоршня, который запускает квест, и после этого 101 фраза больше не доступна
---------------------------------------------------------------------------------------------------
            <phrase id="102">
                <text>my_actor_dialog_102</text>
                <dont_has_info>my_kvest_done</dont_has_info>
                <has_info>my_kvest_start</has_info>
                <next>1021</next>
                <next>1022</next>
            </phrase>

<has_info>my_kvest_start</has_info> проверка того что игрок получил инфопоршень my_kvest_start, пока он не получен ветка диалога не появляется, сама ветка нужна чтобы пока мы не выполнили подзадание в диалоге была затычка.

<dont_has_info>my_kvest_done</dont_has_info> после получения инфопоршня "my_kvest_done" ветка диалога уберается из игры. Та в которой мы завершили квест.
---------------------------------------------------------------------------------------------------
            <phrase id="1021">
                <text>my_actor_dialog_1021</text>
                <precondition>sak.prov</precondition>
                <next>10211</next>
            </phrase>

<precondition>sak.prov</precondition> проверка нужных предметов для того, чтобы фраза в диалоге о том что мы выполнили подзадание стала доступна
---------------------------------------------------------------------------------------------------
            <phrase id="10211">
                <text>my_actor_dialog_10211</text>
                <action>sak.nagrada</action>
                <action>sak.zabral</action>
                <give_info>my_kvest_done</give_info>
            </phrase>

<give_info>my_kvest_done</give_info> собствено сам инфопоршень о завершении квеста
<action>sak.nagrada</action> Это функция где нам дают награду
<action>sak.zabral</action> Это функция где у нас забирают предмет
---------------------------------------------------------------------------------------------------
            <phrase id="2">
                <text>my_actor_dialog_2</text>
                <dont_has_info>my_kvest2_start</dont_has_info>
                <has_info>my_kvest_done</has_info>
                <next>20</next>
            </phrase>

<has_info>my_kvest_done</has_info> При получении "my_kvest2_start" вторая ветка диалога появляется и открывает путь к новым вариациям диалога.
---------------------------------------------------------------------------------------------------	
в \gamedata\config\gameplay\info_portions.xml вставляем наши инфопоршни

  <info_portion id="my_kvest_start">
      <!-- <task>my_kvest</task> -->
  </info_portion>
  <info_portion id="my_kvest_done"></info_portion>
  <info_portion id="my_kvest2_start"></info_portion>
---------------------------------------------------------------------------------------------------
Использующиеся в диалогах скрипты \gamedata\scripts\sak.script

-- Это функция проверки наличия у нас медузы
function prov() 
return sak.have_item_namber("af_medusa",1) ~= false
end

-- У нас забирают вещь
function zabral()
sak.out_item_namber("af_medusa",1)
end

-- Дают награду
function nagrada()
sak.create_items_actor("medkit",3)
sak.create_items_actor("bandage",5)
end

Диалоги в игре можно указывать не только в профиле персонажей, а ещё через логику.
Существует два варианта схема actor_dialogs и meet

как ни крути с actor_dialogs я не разобрался
поэтому давайте разберем meet

в схеме meet первую фразу всегда говорит нпс.


Есть обычная логика волкера к примеру
[logic]
active = walker


и в самой секции волкер устанавливаем параметры meet, вроде можно и в [logic] поместить чтобы применилось ко всем схемам
[walker]
path_walk = wolf_walk
path_look = wolf_look
meet = meet


и сама секция соответственно с указыванием диалога 
[meet]

meet_dialog = test_function


Ещё можно в логике нпс всё оформить так,чтобы он сам открыл диалоговое окно и начал разговор:
[logic]
active = walker

[walker]
path_walk = wolf_walk
path_look = wolf_look
meet = meet

[meet]
use			= {=dist_to_actor_le(2) +my_info1 -my_info2} self,true
meet_dialog = test_function

данная логика подразумевает что нпс будет сам начинать разговор только тогда, когда будет получен инфо my_info1 и будет отсутствовать инфо  my_info2,так же дистанция 2 метра в остальных случаях диалог будем открывать на клавишу как обычно
