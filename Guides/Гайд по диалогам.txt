Параметры диалога
---------------------------------------------------------------------
id - названия

priority - приоритета

<has_info> - инфопоршн для ограничения показа диалога до получения этого\этих поршн(диалог не будет отображаться среди доступных)

<dont_has_info> - инфопоршн для ограничения показа диалога после получения этого\этих поршн(диалог не будет отображаться среди доступных)

<precondition> - функция для ограничения показа диалога до выполнения условий функции - диалог не будет отображаться среди доступных, в этот параметр указывается функция из файла в папке "gamedata/scripts/" подробнее в гайде по скриптам
---------------------------------------------------------------------------------------------------
<dialog id="my_actor_dialog"> Это шапка диалога его айди, диалог закрывается так:
</dialog>
---------------------------------------------------------------------------------------------------
<phrase_list> Обязательная часть диалога - лист фраз, содержит в себе все фразы, закрывается так:
</phrase_list>
---------------------------------------------------------------------------------------------------
Параметры фраз
---------------------------------------------------------------------------------------------------
id - номер фразы

<next> - можно установить, какие фразы будут исходить из этой

<has_info> - инфопоршн для ограничения показа фразы до получения этого\этих поршн(фраза не будет отображаться среди доступных)

<dont_has_info> - инфопоршн для ограничения показа фразы после получения этого\этих поршн(фраза не будет отображаться среди доступных)

<give_info> - выдача инфопоршн 

<disable_info> - удаление инфопоршн 

<precondition> - функция для ограничения показа фразы до выполнения условий функции - фраза не будет отображаться среди доступных

<action> - вызов\выполнение функции

<script_text> - вызов\выполнение функции, которая отображает текст через game.translate_string() Работает в ОГСР/ЧН/ЗП

В параметрах <precondition>, <action> и <script_text>  указываются функции из файлов в папке gamedata/scripts/

подробнее в гайде по скриптам.txt

SCRIPT_TEXT
---------------------------------------------------------------------------------------------------
Нельзя ставить в 0 фразу
Пример:
            <phrase id="1">
                <script_text>sak.create_phrase</script_text>
                <next>2</next>
            </phrase>	

function create_phrase(speaker1, speaker2, dialog_id, phrase_id)
	return game.translate_string(speaker2:character_name())
end

Доступность фраз
Если в диалоге не будет доступной фразы для ответа гг или нпс - случится вылет, поэтому всегда предусматриваем такую фразу

Каждый диалог начинается с 0 фразы, в <actor_dialog> её говорим мы, а нпс нам отвечает фразу 1, либо 2, либо 25, в зависимости от условий их отображения.	

в <actor_dialog> во фразе 0 обязательно должен быть текст
---------------------------------------------------------------------------------------------------
            <phrase id="0">
                <text>my_actor_dialog_0</text>
                <next>1</next>
                <next>2</next>
                <next>25</next>
            </phrase>

в <start_dialog> можно разнообразить первую фразу, для этого не указываем текст в 0 фразе, тогда фраза отображаться не будет, но зачется как прочитанная

Так можно сделать много веток диалогов или приветствий, которые будут показываться в зависимости от выполнения условий

            </phrase>

Во фразе 1000 уже ставим текст, с него начнётся диалог

<dont_has_info>my_kvest_start</dont_has_info> После получения инфопоршн "my_kvest_start" ветка диалога уберается из игры, если не будет сделан disable этого инфопоршн. То есть та ветка, в которой мы соглашаемся взять квест.
---------------------------------------------------------------------------------------------------

                <text>my_start_dialog_101111</text>
                <give_info>my_kvest_start</give_info>
                <next>1011111</next>
            </phrase>

<give_info>my_kvest_start</give_info> Это выдача инфопоршн, который запускает квест, и после этого 101 фраза больше не доступна
---------------------------------------------------------------------------------------------------
            <phrase id="102">
                <text>my_actor_dialog_102</text>
                <dont_has_info>my_kvest_done</dont_has_info>
                <has_info>my_kvest_start</has_info>
                <next>1021</next>
                <next>1022</next>
            </phrase>

<has_info>my_kvest_start</has_info> проверка того что игрок получил инфопоршн my_kvest_start, пока он не получен ветка диалога не появляется, сама ветка нужна для того, чтобы пока не выполнено подзадание в диалоге была доспупная фраза.

<dont_has_info>my_kvest_done</dont_has_info> после получения инфопоршн "my_kvest_done" ветка диалога уберается из игры. Та в которой мы завершили квест.
---------------------------------------------------------------------------------------------------
            <phrase id="1021">
                <text>my_actor_dialog_1021</text>
                <precondition>sak.prov</precondition>
                <next>10211</next>
            </phrase>

<precondition>sak.prov</precondition> проверка нужных предметов для того, чтобы фраза в диалоге о том, что мы выполнили подзадание - стала доступна
---------------------------------------------------------------------------------------------------
            <phrase id="10211">
                <text>my_actor_dialog_10211</text>
                <action>sak.nagrada</action>
                <action>sak.zabral</action>
                <give_info>my_kvest_done</give_info>
            </phrase>

<give_info>my_kvest_done</give_info> выдача инфопоршн о завершении квеста
<action>sak.nagrada</action> Это функция где нам дают награду
<action>sak.zabral</action> Это функция где у нас забирают предмет
---------------------------------------------------------------------------------------------------
            <phrase id="2">
                <text>my_actor_dialog_2</text>
                <dont_has_info>my_kvest2_start</dont_has_info>
                <has_info>my_kvest_done</has_info>
                <next>20</next>
            </phrase>

<has_info>my_kvest_done</has_info> При получении инфо "my_kvest2_start" вторая ветка диалога - появляется и открывает путь к новым вариациям диалога.

Диалоги в игре можно указывать не только в профиле персонажей, а ещё через логику.
Существует два варианта схема [actor_dialogs] и [meet]

как ни крути с [actor_dialogs] я не разобрался
поэтому давайте разберем [meet]

в схеме [meet] первую фразу всегда говорит нпс - т.е. <start_dialog>.


Есть обычная логика волкера к примеру
[logic]
active = walker

и в самой секции волкер устанавливаем параметры meet, вроде можно и в [logic] поместить, чтобы применилось ко всем схемам
[walker]
path_walk = wolf_walk
path_look = wolf_look
meet = meet


и сама секция соответственно с указыванием диалога, можно задать условие отображения, а так же несколько диалогов
[meet]
meet_dialog = test_function


Ещё можно в логике нпс всё оформить так,чтобы он сам открыл диалоговое окно и начал разговор:
[logic]
active = walker

[walker]
path_walk = wolf_walk
path_look = wolf_look
meet = meet

[meet]
use			= {=dist_to_actor_le(2) +my_info1 -my_info2} self,true
meet_dialog = test_function

данная логика подразумевает что нпс будет сам начинать разговор только тогда, когда будет получен инфо my_info1 и будет отсутствовать инфо  my_info2,так же дистанция 2 метра в остальных случаях диалог будем открывать на клавишу как обычно

function init_simple_exchange_dialog(dlg)
  dlg:SetForceReload(true) -- было добавлено в ОГСР, для повторной загрузки диалога после сейва

    local phr0 = dlg:AddPhrase("Певая фраза", "0", "", -10000)

    local phr1 = dlg:AddPhrase("Вторая фраза", "1", "0", -10000)
    
    local phr2 = dlg:AddPhrase("Третья фраза", "2", "1", -10000)
  
    local phr3 = dlg:AddPhrase("Четвертая фраза", "3", "2", -10000)
end
