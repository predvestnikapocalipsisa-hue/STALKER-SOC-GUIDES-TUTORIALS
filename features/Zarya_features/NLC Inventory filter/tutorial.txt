================================================================================================================================

	Фильтр предметов инвентаря - довольно локальная темка, в нлс 7 при выбирании какой-либо категории предметов в разгрузке
	
	открывается инвентарь, но с предметами выбранной категории. То есть все остальное скрывается.
	
	Этот скрипт реализует это на движке OGSR
	

================================================================================================================================	

	Для адаптации привязываем on_hide_inventory() к инфопоршню закрытия инвентаря.
	
	То есть, в function actor_binder:info_callback(npc, info_id) делаем такую вещь
	
		if info_id=="ui_inventory" then

		elseif info_id=="ui_inventory_hide" then	
			filter_inventory.on_hide_inventory()
		end		
		
	В скриптах применение этого скрипта выглядит вот так:
	
			filter_inventory.open_filtered_inventory(function(item) 
    			return item:is_ammo() or item:is_artefact() -- тут мы делаем проверку, какие предметы будут показаны в инвентаре
			end)
