Итого:
Как предмет выступает inv_ruck, его можно ставить в продажу и тд.

Как неподвижный объект выступает active_ruck, его без проблем можно спавнить скриптом на координатах:
function my_name()
alife():create("active_ruck",vector():set(-152.0,-18.0,-144.3),98126,45)
end


А так же если хотите через скрипт спавнить такой рюкзак со своим набором предметов и по координатам, то в config\misc\devices.ltx ниже добавляем:
[active_ruck_my]:active_ruck
$spawn = "devices\active_ruck_my";обязательно для СДК
custom_data = scripts\active_ruck_my.ltx

Далее создаем \gamedata\config\scripts\active_ruck_my.ltx
и вставляем этот код
[logic]
active = ph_idle@enable

[ph_idle@enable]
nonscript_usable = true
tips = st_search_treasure

[spawn]
wpn_pm
wpn_ak74


А саму функцию спавна по координатам делаем так 
function my_name()
alife():create("active_ruck_my",vector():set(-152.0,-18.0,-144.3),98126,45)
end

Как её использовать ищем в моём гайде по скриптам.

Таких рюкзаков с заранее заспавнеными вещами может быть много, НИЧЕГО НЕ НУЖНО добавлять в bind_stalker.script
